# GPUDock 使用指南

## 1. 登录

打开 GPUDock，点 **用 Google 登录**。浏览器会打开 Google 授权页：

1. 选择你要用来跑 Colab 的 Google 账号；
2. 在“选择 GPUDock 可以访问的内容”里点 **全选**，一定要勾上 **Colab**；
3. 看到“GPUDock 登录完成”后回到 GPUDock。

令牌保存在系统钥匙串里。退出登录：点右上角头像 → 退出登录。

## 2. 启动一张显卡

在 **显卡** 页挑一张卡，点 **启动**。

| 卡 | 显存 | 适合 |
|---|---|---|
| T4 | 15 GB | 转写、朗读、配音（预置音色），最容易拿到 |
| L4 | 22.5 GB | 配音全流程、声音克隆，性价比最高 |
| A100 | 40 / 80 GB | 大模型、视频生成 |
| RTX PRO 6000 | 96 GB | 超大模型 |
| H100 | 80 GB | 旗舰（需要 Pro/Pro+） |

- Colab 那边这张卡暂时没货时，GPUDock 会**自动排队重试**：每 45 秒试一次，最多等 20 分钟，卡片上会显示“排队中（第 n 次）”，随时可以点“取消排队”。
- 右上角的 **空闲自动释放** 默认 30 分钟：运行时空闲超过这个时间，就会被自动释放以节省计算单元。只会释放 GPUDock 自己创建的运行时。
- 用完点 **释放**，计费立即停止。运行时里的文件和已部署的模型会一起清掉，但已经下载到你电脑上的产出文件不受影响。

## 3. 模型库

批量任务会**自动部署**用到的模型，不需要先来这里。你也可以在这里提前部署或试用：

| 模型 | 用途 | 许可证 | 部署时间 |
|---|---|---|---|
| Whisper（faster-whisper） | 语音转文字 | MIT | 约 2 分钟 |
| Demucs | 人声与背景分离 | MIT | 约 1 分钟 |
| Kokoro | 预置音色朗读（中 / 英 / 日 / 西 / 法 / 意 / 葡 / 印地） | Apache-2.0 | 约 2 分钟 |
| VoxCPM2 | 声音克隆、30 种语言（需要 L4 / A100 或 T4 高内存版） | Apache-2.0 | 约 5 分钟 |
| 大模型（Ollama） | 字幕翻译、对话；可选 Qwen3 8B、Qwen3.8 27B / Flash Next、Inkling-2 Mini | Apache-2.0 等 | 约 4 分钟起 |

部署只对当前这个运行时有效，换一个新运行时需要重新部署。

页面下方是 **生图与生视频** 模型，可以提前把权重下载到运行时（视频模型动辄几十 GB，第一次下载要几分钟到十几分钟）。

## 创作：生图与生视频

1. 选模型。视频：Wan2.2 5B（最省显存，L4 就能跑）、Wan2.2 A14B、LTX-2.5（画面带声音）、MiniMax H3（带对白音效，最长 15 秒）；图像：Z-Image Turbo（T4 可跑）、Qwen-Image 2.1、FLUX 3 Klein、MiniMax H3 Image；
2. 选显卡。每个模型都标了推荐显卡和显存，视频模型建议 A100 / RTX PRO 6000 / H100；
3. 写提示词，选模式（文生、图生、首尾帧、参考图、图像编辑），需要时拖入图片，选画幅、时长和种子；
4. 点 **生成**。第一次会自动部署 ComfyUI 并下载模型，之后同一个运行时再生成就快了。

生成用的是 ComfyUI 官方工作流模板，结果文件旁边会附上实际运行的 API 格式工作流（`*.workflow-api.json`），可以拖进自己的 ComfyUI 复现。

**需要授权的模型**：LTX-2.5、FLUX 3 Klein 的权重在 Hugging Face 上需要先申请访问。打开模型页点同意许可，再在 huggingface.co/settings/tokens 建一个只读 Token，填到“创作”页里。Token 保存在本机钥匙串，只在下载时临时传给运行时。

**许可**：每个模型的许可证和商用条件都写在卡片上。MiniMax H3 的许可不覆盖欧盟、英国、美国和韩国，年收入超过 2000 万美元需要另行授权；LTX-2.5 年收入 1000 万美元以上需要购买授权。

## 4. 批量转写

1. 选择显卡，拖入音频或视频（可以多选）；
2. 选模型（默认 Turbo，又快又准）、语言、输出格式；
3. 点 **开始转写**。

结果会按句切分，中文使用全角标点。产出文件保存在 `~/GPUDock/outputs/<任务>/`，任务完成后点“在文件夹中显示”即可打开。

## 5. 批量配音

1. 拖入视频或音频；
2. 选原语言（可以自动识别）和目标语言；
3. 选翻译方式：
   - **运行时内 Qwen3**：免费，在你的 Colab 运行时里翻译；
   - **外部 API**：任何 OpenAI 兼容接口（DeepSeek、通义千问、OpenAI 等）。密钥存在你的电脑上，不会上传到 Colab；
   - **不翻译**：同语言重新配音。
4. 选声音：
   - **预置音色**（Kokoro）：快，可商用；
   - **克隆原声**（VoxCPM2）：用视频里说话人的声音说目标语言，需要先确认你有授权。它加载时约需 10 GB 内存，T4 标准版不够，请用 L4、A100 或 T4 高内存版。
5. 建议打开 **翻译后先让我校对**：译文出来后，任务会暂停在“等你校对”，你可以逐句修改，再点“确认并开始配音”。
6. 打开 **保留背景音乐和音效**：先用 Demucs 去掉原人声，再把配音混进原背景。

**产出文件**

| 文件 | 内容 |
|---|---|
| `xxx.dubbed.mp4` | 配音后的视频（视频画面不重新编码，画质无损） |
| `xxx.dubbed.wav` | 配音后的完整音轨 |
| `xxx.dubbed.srt` | 译文字幕 |
| `xxx.bilingual.srt` | 双语字幕（译文 + 原文） |
| `xxx.segments.json` | 每句的时间、原文和译文 |

**为什么有些句子听起来更快？** 译文比原句长时，GPUDock 会把这句配音加速，最多到 1.35 倍，好放进原来的时间段。还是放不下的会在下一句开始前截断。所以校对时把译文改短一点，效果会更自然。

## 6. 批量朗读

每行文字生成一个音频文件，可以额外合并成一整段。可以先点 **试听第一句** 听听效果。用 VoxCPM2 时可以上传一段 5–15 秒的清晰人声作为参考音色。

## 7. 控制台

在显卡页点开一个运行时，就能直接执行 Python 或 `!命令`，例如 `!nvidia-smi`、`!pip install ...`。这个运行时上的变量会一直保留，直到运行时被释放。

## 常见问题

**登录时提示“此应用未经验证”或“403 access_denied”？** 你用的是开发版，应用还在测试状态，只有维护者加进测试用户名单的账号才能登录。正式发布版不会有这个问题。

**登录后浏览器卡在 `localhost:xxxxx`？** 代理软件把 localhost 也转发出去了，请在代理设置里让 `localhost` / `127.0.0.1` 直连。

**免费账号能用吗？** 能用 T4 等显卡，但 Colab 对免费账号用 Web 界面做重度内容生成有终止风险，建议账号里留一点计算单元再批量跑。

**生成时提示显存不够？** 降低分辨率或时长，或换显存更大的卡。视频模型在 L4（24 GB）上只适合 Wan2.2 5B。

**提示运行时磁盘不够？** Colab 运行时的磁盘有限，几个大视频模型同时下载可能放不下。释放这张卡重新启动一张（磁盘会清空），只下载要用的那个模型。

**会花多少钱？** 界面上显示的是估算：T4 每小时约 1.2 个计算单元，约 0.12 美元。记得用完释放，或者打开空闲自动释放。
